# Les starters par défaut

Pour offrir une flexibilité totale, Grimoire repose sur deux starters fondamentaux. Ces outils sont les pierres angulaires du framework : ils vous permettent de passer d'un simple utilisateur à un créateur d'écosystème.

## Créer une CLI sur mesure avec "custom-cli"

Le starter **custom-cli** est conçu pour ceux qui souhaitent bâtir leur propre interface de ligne de commande personnalisée. Bien plus qu'un simple modèle, il automatise toute la structure nécessaire pour :

*   **Développer** votre propre logique de commande.
*   **Partager** facilement votre outil via NPM.
*   **Offrir** à vos utilisateurs finaux la capacité d'étendre eux-mêmes votre CLI grâce à la gestion native du dossier `.cli` local.

C'est l'outil idéal pour standardiser les processus au sein de votre organisation.

## Partager des ressources avec "custom-tome"

Si votre objectif est de distribuer des briques réutilisables, le starter **custom-tome** est votre point d'entrée. Un "Tome" est un package NPM spécialisé qui permet de :

*   **Regrouper** des générateurs de code complexes.
*   **Diffuser** des configurations de frameworks entiers.
*   **Modulariser** vos outils pour que chaque équipe puisse piocher uniquement ce dont elle a besoin.

Ensemble, **custom-cli** et **custom-tome** forment le moteur qui rend Grimoire véritablement extensible et collaboratif.
