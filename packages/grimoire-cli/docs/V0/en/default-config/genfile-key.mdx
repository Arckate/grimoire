# Generation Files Configuration

These keys define the format and structure of the data files generated by the CLI (`.gen` type files).

## Properties and Default Values

### `planExt`
- **Type**: `string`
- **Default value**: `"json"`
- **Description**: Defines the extension of the generated files. This allows switching between different data formats, for example, to obtain a `.plan.json` or `.plan.yaml` file.

### `planType`
- **Type**: `string` (e.g., `"camelCase"`, `"pascalCase"`, `"snakeCase"`)
- **Default value**: `"camelCase"`
- **Description**: Defines the naming convention (case) used for the keys inside the generated files.

---

## Application Example

If you configure the CLI to generate YAML files in PascalCase:

**Configuration:**
```json
    {
        "planExt": "yaml",
        "planType": "pascalCase"
    }
```

**Generated Result (`example.plan.yaml`):**
```yaml
# Keys are converted to PascalCase
UserInformation:
    FirstName: "John"
    LastName: "Doe"
```

- **File Name**: The extension has become `.yaml`.
- **Key Format**: Properties follow the **PascalCase** rule.
